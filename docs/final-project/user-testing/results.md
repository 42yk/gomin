# 고민일기 사용자 테스트 결과

## 테스트 개요

실사용자 **5명**이 [배포한 고민일기](https://www.gomin.today)를 이용하고 대면으로 의견을 전달했다. 참여 인원·배포 환경·수집 방식은 프로젝트 담당자가 확인했다.

참여자는 기획 타겟과 다른 사용자들이다. 이번 결과는 서비스의 사용성과 AI 결과에 관한 초기 피드백이며, 만 10~24세 타겟 전체의 필요나 선호를 검증한 결과로 해석하지 않는다.

## 수집한 의견

| ID | 구분 | 사용자 의견 |
| --- | --- | --- |
| FB-01 | 입력 | 털어놓기에 들어가면 바로 입력할 수 있으면 좋겠고, 채팅창의 초록색 박스는 없으면 좋겠다. |
| FB-02 | 상세 화면 | 컬렉션 상세에서 왼쪽에는 그림, 오른쪽에는 요약을 보고 싶다. |
| FB-03 | 메뉴 이름 | 헤더의 ‘홈’보다 ‘털어놓기’처럼 목적을 알 수 있는 이름이 좋겠다. |
| FB-04 | 접근성 | 키보드로 더 편하게 이용할 수 있으면 좋겠다. |
| FB-05 | 로딩 안내 | 대화 내용이 늦게 나타날 때 불러오는 중인지 표시해 주면 좋겠다. |
| FB-06 | 대화 품질 | 다음 고민을 유도하는 대화가 불편하고 응답이 정형적으로 느껴진다. |
| FB-07 | 이미지 품질 | 생성된 그림이 대화 내용과 무관하게 느껴진다. |

위 문장은 전달받은 의견의 뜻을 유지해 다듬었다. 녹취를 옮긴 직접 인용은 아니다. 개인별 발언이나 항목별 응답 인원은 배정하지 않았다.

## 결과 해석

사용자는 입력을 시작하고 결과를 읽는 과정뿐 아니라 기다리는 동안의 안내에도 불편을 느꼈다. 자동 초점, 상세 화면의 좌우 배치, 로딩 표시처럼 이용 흐름을 분명하게 만드는 개선으로 연결했다.

AI에 대해서는 대화가 정형적이라는 점과 그림이 자신의 이야기와 연결되지 않는다는 의견이 있었다. 대화를 길게 유지하기보다 현재 고민과 사용자의 의사에 집중하고, 그림의 장면에 고민의 구체적인 상황을 담도록 프롬프트를 수정했다.

## 결과의 범위

확인된 결과는 참여자 수, 진행 환경·수집 방식, 7개 의견과 관련 수정 이력이다. 만족도·과제 성공률·응답 시간·개선 후 평가의 수치는 수집 근거가 없어 기재하지 않았다. 코드 변경만으로 불편이 해소됐다고 판단하지 않는다.
